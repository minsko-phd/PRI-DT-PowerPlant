# 🌊 시화호 조력발전소 디지털 트윈 — 발전량 최적화 3D 시뮬레이션 데모

경기도 안산 **시화호 조력발전소**(K-water)를 대상으로 한 통합 운영 디지털 트윈(DT)
제안의 핵심 메시지 — *“같은 조석으로 더 안정적이고 더 많이 발전한다”* — 을
**브라우저에서 바로 돌아가는 3D 시뮬레이션**으로 표현한 데모입니다.

> 첫 미팅 제안(2026.06.19) 컨셉: 여러 기술이 DT 하나로 통합 · 영상/이미지 위주 ·
> K-TOP 4.0과 **병행 교차검증(Shadow Mode)** · **사람이 최종결정(Human-in-the-loop)** ·
> 정체성 = “조력발전소 Plant OS”.

별도 빌드/설치 없이 브라우저에서 바로 실행됩니다. (Three.js를 CDN으로 로드)

```bash
# 방법 1) 그냥 더블클릭
index.html  →  브라우저로 열기

# 방법 2) 로컬 서버 (권장 — CDN 로드 안정적)
python3 -m http.server 8080
#  → http://localhost:8080  접속
```

## 🎮 데모에서 보여주는 것

### 1) 시화호 조력발전소의 “모습”을 디테일하게 3D로 재현
- **방조제(12.7km 중 발전 구간)** — 상부 왕복도로·난간·차선
- **발전동(파워하우스)** — **벌브형 수차발전기 10기**(25.4MW×10 = 254MW),
  바다↔호소를 관통하는 통수로와 **회전하는 러너(프로펠러)**
- **수문부(슬루스 게이트) 8문** — 콘크리트 피어 + **상하로 움직이는 강재 게이트** +
  권양 트러스/모터, 배수 시 게이트가 실제로 올라갑니다
- **시화나래 전망대** 랜드마크, 바다(서해)·시화호 양측 수면, 햇빛·그림자

### 1-b) 유체·터빈·수위를 실시간으로 “화려하게” 가시화
- **터빈 회전**: 발전 중 흡입구의 벌브 프로펠러 + 내부 러너가 **낙차에 비례한 속도로 회전**, 흡입 림이 발광
- **유체 흐름·유량**: 통수(노란빛)·배수(푸른빛) 입자가 흐르고, **실제 통수량(㎥/s)에 비례해** 입자 밀도·크기·물보라가 증가 (가산 블렌딩)
- **물보라/포말**: 발전 시 호소측 유입 포말, 배수 시 바다측 물보라가 유량만큼 분출
- **수위**: 바다·호소 수면이 실제 수위로 오르내리고, 좌우 **발광 수위 게이지 링**이 수면 높이를 가리킴
- **실시간 라벨**: 발전소 상공에 **낙차 H · 통수량 ㎥/s · 출력 MW · 운전 단계**가 3D 라벨로 표시

### 2) 발전 원리(단류식 창조발전)를 물리로 시뮬레이션
시화호는 **세계 최대 단류식(창조) 조력발전** — 밀물 때 바다→호소로 통수하며 발전하고,
썰물 때 수문을 열어 호소를 배수합니다. 데모는 이 1주기(약 12.4시간)를 4단계 상태기계로 구현합니다.

```
① 낙차 축적(수문 닫힘) → ② 발전(바다→호소 통수) → ③ 만조 정체 → ④ 배수(수문 개방) → 반복
```

- 조석: `해수면 = 평균 + 진폭·sin(2π·t/12.42h)` (조차 ≈ 7.8m)
- 터빈 출력: `P = η·ρ·g·Q·H` (낙차 H, 통수량 Q, 정격 25.4MW 제한)
- 호소 수위: 유입(터빈)–배수(수문) **체적 수지**로 실시간 변화

### 3) “발전량을 최대로” — 운전 전략 최적화 인터랙션
오른쪽 패널에서 직접 운전 변수를 바꿔 가며 **누적 발전량/일·연 환산/설계목표 552GWh 대비 %**가
어떻게 달라지는지 비교할 수 있습니다.

| 제어 변수 | 의미 | 트레이드오프 |
|---|---|---|
| **발전 개시 낙차** | 얼마의 낙차에서 발전을 시작할지 | 낮추면 발전시간↑·저낙차 손실↑ → **최적점 존재** |
| **발전 종료 낙차** | 어느 낙차까지 발전을 끌고 갈지 | 효율 하한 관리 |
| **가동 터빈 수** | 동시 가동 대수 | 적게=오래·저출력 / 많이=빨리·고출력 |
| **배수 수문 수** | 개방 수문 수 | 배수 속도 → 다음 주기 준비 |
| **조석 조차** | 대조(사리)~소조(조금) | 조차↑ → 낙차·발전량↑ (대조 시 peak 254MW) |

#### 📈 자동 최적화 스윕 (핵심 데모 기능)
**[발전량 vs 개시 낙차 자동 계산]** 버튼을 누르면, 현재 조석 조건에서 개시 낙차를
0.4~4.0m까지 자동으로 훑어 **발전량 곡선을 그리고 최적점(★)을 표시**합니다.
- 곡선이 **왼쪽에서 붕괴**(너무 일찍 발전 → 낙차를 못 키워 출력 0)하고,
  **중앙에서 봉우리**를 이룬 뒤 **오른쪽에서 완만히 감소**(밀물 시간 낭비)하는 모습을 한눈에 확인
- **[★ 최적값 적용]** → AI 최적 운전으로 전환, 슬라이더가 자동으로 최적값으로 이동
- 평균 조차(6.6m)에서 최적 개시낙차 ≈ **2.8m → 연 환산 552GWh**(실제 설계 발전량과 일치)

- **수동 운전 ↔ AI 최적 운전** 토글 — AI 모드는 현재 조석에 맞춰 **헤드리스 스윕으로 최적값을 자동 산출**
  (제안서의 *“자동 수문 운전 AI + 운영전략 AI”*, *“조석·설비 상태 종합 → 발전량 추천, 사람이 확정”* 컨셉)
- 시점 전환(조감/바다측/발전동 근접/육지측/평면), **전체화면**, 일시정지·리셋, 시뮬 속도(최대 400×)
- **🎬 시네마틱 자동 투어**: 발전소를 따라 카메라가 부드럽게 순회(발표용) — 화면 클릭 시 해제
- **🌙 야간/조명 모드**: 야경 전환 — 발전동·수문·전망대·가로등 점등, 별·달빛, 발광 게이지/터빈
- **💧 수면 반사**: 잔잔한 호소는 방조제·전망대를 비추는 **평면 거울 반사**, 바다는 하늘을 반사하는 광택 수면(IBL)
- **LG PRI 브랜딩**: 우측 상단 LG 로고 배지 + 발전동 옥상 LG PRI 사인보드(3D)

## 🎬 데모 시연 가이드 (발표용 약 3분)

1. **로딩 후 조감뷰**에서 시작 → 마우스 드래그로 발전소를 한 바퀴 둘러보며
   *“25.4MW 수차 10기, 수문 8문, 시화나래 전망대”* 설명
2. **[🎥 시점 전환]** 으로 발전동 근접뷰 → 발전 중 **터빈 러너 회전 + 바다→호소 통수(노란 흐름)** 강조
3. 좌측 패널에서 **발전 개시 낙차 슬라이더**를 좌우로 움직이며
   상단 **현재 출력(MW)** 과 우측 하단 **연 환산 GWh** 가 바뀌는 것을 시연
4. **[발전량 vs 개시 낙차 자동 계산]** 클릭 → 곡선과 ★최적점 등장 →
   *“너무 일찍 시작하면 출력이 붕괴, 너무 늦으면 손해 — 최적점은 여기”* 설명
5. **[★ 최적값 적용]** → **AI 최적 운전** 전환 → 연 환산이 **552GWh(목표 100%)** 에 도달
6. (선택) **조석 조차**를 대조로 올려 peak **254MW** 도달, 또는 **시뮬 속도**를 높여
   4단계 사이클(축적→발전→정체→배수)이 반복되는 것을 빠르게 시연

> 발표 팁: **[⛶ 전체화면]** 후 좌측 패널만으로 모든 조작이 가능합니다.

## 🧠 제안하는 DT에 대한 이해 (요약)

자세한 내용은 [`docs/DT-제안-이해.md`](docs/DT-제안-이해.md).

- **목적**: 시화호 조력발전소 **통합 운영 디지털 트윈** — 발전·수질·방재·안전을 한 화면으로
- **포지셔닝**: K-TOP 4.0 **대체가 아닌 병행 교차검증(Shadow Mode)**, **사람 최종결정**
- **4계층 Plant OS**: 데이터 수집 → 표준화/맥락화 → 지능(AI Agent·Digital Twin) → 통합 운영
- **핵심 아이템**: ① 자율운영 AI Agent ② 가상훈련·보전 시뮬 ③ Plant OS 통합 ④ 확장기술 6선
- **기반**: NVIDIA Omniverse · OpenUSD · PhysicsNeMo(CFD 물리시뮬)
- **효과 메시지**: 돌발 정지 1일 ≈ **1.5GWh 손실** 방지 · 노하우 자산화 · 통합 가시성

> 이 데모는 그 중 **“발전 최적화 + 설비(수차·수문) 3D 가시화”** 부분의
> 개념 검증(PoC)에 해당합니다.
