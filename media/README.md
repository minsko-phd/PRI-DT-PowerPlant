# 🎬 시화호 조력발전소 디지털 트윈 — 데모 영상

모든 영상은 헤드리스 Chromium(WebGL)으로 `index.html`을 결정론적으로 렌더링하여 ffmpeg로 인코딩했습니다.

## 발전량 최적화의 중요성 — 베스트 vs 워스트 (동일 조석 조건)

| | 운전 전략 | 약 1.2일 누적 발전 |
|---|---|---|
| ✅ **BEST** | AI 최적 운전 · 개시낙차 **2.8m** | **2.50 GWh** |
| ⚠️ **WORST** | 비효율 운전 · 개시낙차 **0.6m** (조급한 발전 → 낙차 형성 실패) | **931 MWh** |

→ **같은 바다·같은 설비인데 운전 전략만으로 발전량이 약 2.7배** 차이. 디지털 트윈 최적화의 가치를 보여줍니다.

- `sihwa_best_vs_worst.mp4` / `.gif` — 좌(BEST)·우(WORST) 동시 비교
- `sihwa_best.mp4` — 베스트 단독
- `sihwa_worst.mp4` — 워스트 단독
- `sihwa_dt_demo.mp4` / `.gif` — 시네마틱 투어(AI 최적 운전, 주간→야간)

화면에 **경과 시간**, **Σ 총 누적 발전량(MWh/GWh)**, 현재 출력(MW), 낙차·수위·운전 단계가 실시간 표시됩니다.
